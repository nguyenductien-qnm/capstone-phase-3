# TechX Corp - MANDATE-14 Submission Report
## AI Copilot Guardrails & Telemetry Completion

### 1. Executive Summary
This report formally concludes the execution of MANDATE-14 for the TechX Corp Shopping Copilot. We have successfully implemented, evaluated, and verified a robust set of security guardrails (Prompt Injection, PII leakage, Off-topic restriction) and automated telemetry.

### 2. Key Accomplishments
* **Performance & Reliability Improvements (Phase 1):**
  * Upgraded `SimpleConnectionPool` to `ThreadedConnectionPool` in `product-reviews/database.py` and added connection pooling to `recommendation_server.py`, resolving connection exhaustion under concurrent load.
  * Successfully initialized semantic search vector databases and ensured robust retrieval via `Amazon Titan Text Embeddings`.
  * Resolved HTTP 500 errors caused by service startup ordering (dependent services not yet ready when copilot boots).
* **Automated Evaluation Harness (Phase 2 & 3):**
  * Created a structural automated test suite (`docs/ai/evals/eval_mandate14.py`) running against the Copilot's `/api/copilot` endpoint.
  * The harness scores by examining `actionsTaken` (tool calls + `succeeded` flag), OpenTelemetry spans (`guardrail.blocked`, `app.search.mode`, `gen_ai.usage.*`), and citations — it does NOT use LLM-as-a-judge.
  * Pass rates: see latest evidence directory for exact numbers.
* **Automated Trace Audit (Phase 4):**
  * Full observability implemented utilizing OpenTelemetry JSON evidence artifacts.
  * Confirmed that Semantic Search, Titan Embedding invocation, Output guardrails, and specific intent tools (intent_6: `convert_currency` + `get_shipping_quote`) are explicitly captured in OpenTelemetry spans.
  * `trace_audit.py` defaults to auditing the **latest** evidence directory only; `--dirs` for explicit multi-dir audit, `--all` with warning. Each check prints which directory satisfied it.
* **Architectural Decisions (Phase 5):**
  * Drafted and signed **ADR-015** in `docs/ai/05_adrs.md`, detailing:
    - The 6-metric framework (Injection Block Rate, False Block Rate, Abstention Rate, Faithfulness Rate, Hallucination Rate, Task Success Rate).
    - Scoring architecture: harness checks structure (tool calls, spans), LLM-judge lives in ml-guard as a runtime rail.
    - Corrected LLM pricing: Nova Pro $0.80/$3.20, Nova Lite $0.06/$0.24, Nova Micro $0.035/$0.14, Titan Embed v2 $0.02.
  * Implemented an automated execution script (`docs/ai/evals/repro.sh`) to reproduce the eval runs with `--enforce-hard-bars`.
  * Cost and latency tracked via `cost_before_after.py` → `cost_latency_report.md` (same pricing applied to all runs for apples-to-apples comparison).

### 3. Verification Artifacts
- **Eval Harness Report**: `docs/ai/evals/eval_mandate14_report.md`
- **Cost/Latency Report**: `docs/ai/evals/cost_latency_report.md` (generated by `cost_before_after.py`)

### 4. Known Limitations
- p95 latency ~18s, occasional spikes to 30s when Bedrock is slow. If a case hits 504, it is classified as infrastructure error, not a scoring fix.
- "Before" evidence (`evidence/20260725_233709`) may not have span data — the harness at that time did not capture spans. Cost/token columns show `n/a` for those runs.

### 5. Conclusion
The TechX Shopping Copilot meets the security and reliability standards mandated by MANDATE-14. All evidence is traceable to specific eval runs.
